## Featured Projects

### 🐝 Project Honeybee — Indic Smart Speaker System
*(Gemini Live API · OpenWakeWord · Golang · Tauri · Rust · React · Flutter · Home Assistant · BLE · Docker · Cloudflare)*

A production-grade, voice-first smart home system built entirely from scratch — hardware, firmware, cloud backend, and mobile app — with native support for Tamil, Telugu, Hindi, and other Indic languages.

**Hardware**
- **Queenbee** *(Radxa Zero 2 Pro SBC)* — Runs Home Assistant in Docker, an AI personalisation server with user-configurable personas (Friend, Life Partner, Teacher), always-on wakeword detection, real-time Gemini Live audio streaming, emotion-reactive display, and a front-facing camera
- **Workerbee** *(Radxa Zero 3W SBC)* — Lightweight satellite device handling wakeword detection, Gemini Live streaming, and emotion display

**System Architecture**
- **Gemini Live API** — Real-time multimodal Indic language understanding; replaces fragile STT + NLU + intent pipeline stacks
- **OpenWakeWord** — Always-on, on-device wakeword detection
- **Golang backend** — Secure ephemeral API token generation for client device authentication
- **Home Assistant MCP server** — Extensible smart home tool integration via Model Context Protocol
- **BLE provisioning service** — Zero-friction device onboarding with WiFi credential sharing over Bluetooth
- **Cloudflare Tunnel** — Secure remote access to on-device Home Assistant instance
- **Tauri (Rust + React)** — On-device UI for provisioning, camera capture, brightness/volume controls
- **Flutter mobile app** — Full control plane: device management, AI persona configuration, conversation history, smart home control

*(C++ · CANopen · ROS · MoveIt · Linux)*

Designed and implemented a real-time control architecture for a 6-axis robotic manipulator. Built the industrial communication layer using the CANopen protocol and integrated motion planning and kinematics using ROS and MoveIt.

**Key engineering decisions:**

- CANopen network configuration, node management, and PDO/SDO communication
- Forward and inverse kinematics integration with MoveIt motion planner
- Embedded systems integration with the robotics control software stack
